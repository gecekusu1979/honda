# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or critical issue in HondaTuner V2, please do NOT create a public issue. Instead, report it through the following channels:
1. Contact the maintainers or email: `ayhan43huseyin@gmail.com`
2. Provide details, reproduction steps, and potential exploit vectors. We will respond promptly and draft a fix.

## Verification of Release Integrity

To protect yourself from compromised copies or malicious distributions of this software:
- Always compile the code directly from the master repository.
- If using pre-compiled releases, always check the **SHA-256 checksum** of downloaded files and compare them with the official hashes published on the GitHub Releases page.
- Never download or run binaries from untrusted download locations or third-party forks.
